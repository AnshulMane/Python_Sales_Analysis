# 📊 Sales Data Analysis Project

**📌 Project Title:**  
Sales Data Analysis Using Python

**🎯 Objective:**  
To analyze 12 months of retail sales data to uncover patterns in sales, identify peak sales periods, top-performing cities, and recommend optimal advertisement times and product bundling strategies to boost revenue.

**🛠 Tools Used:**  
- 🐍 Python  
- 📒 Jupyter Notebook  
- 🧮 Pandas  
- 📈 Matplotlib  
- 🗂 CSV files  

**🧩 Steps/Approach:**  
1. **🧹 Data Cleaning**  
   - Removed missing values  
   - Filtered out incorrect entries (e.g., header rows in between)  
2. **🧠 Feature Engineering**  
   - Extracted new columns: Month, City, Hour, and Grouped Products  
3. **📊 Analysis Performed**  
   - Monthly Sales Trends  
   - Sales by City  
   - Optimal Advertisement Hours  
   - Frequently Bought Together Products  
4. **🎨 Visualization**  
   - Used Matplotlib to plot sales trends and patterns  

**🔍 Key Outputs or Insights:**  
- 🗓 **Best Month for Sales:** December  
- 🌆 **Top Performing City:** San Francisco  
- ⏰ **Best Ad Timing:** Around 7 PM  
- 📦 **Most Bought Together Products:** iPhone & Lightning Charging Cable  

**📈 Result/Impact:**  
This project demonstrates the ability to process raw business data and extract meaningful insights using the data analysis life cycle. The results can be directly used by marketing and operations teams for revenue optimization and strategy planning.
